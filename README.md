# API CEP - Lazarus

API REST desenvolvida em Lazarus / Free Pascal para consulta de CEP, endereço e código IBGE de municípios.

## Objetivo

Disponibilizar um serviço HTTP para que sistemas da empresa possam consultar informações de endereços através do CEP, utilizando o serviço ViaCEP.

## Tecnologias

- Lazarus 4.8
- Free Pascal
- API REST / HTTP
- ViaCEP
- Git e GitHub
- Postman

## Funcionalidades previstas

- [ ] Criar servidor HTTP.
- [ ] Consultar CEP através do ViaCEP.
- [ ] Retornar dados completos do endereço.
- [ ] Retornar código IBGE do município.
- [ ] Validar CEP inválido ou inexistente.
- [ ] Testar endpoints com Postman.
- [ ] Executar no Windows.
- [ ] Compilar e executar no Linux (Ubuntu).

## Exemplo de consulta

`GET /cep/12240000`

## Ambiente de desenvolvimento

Desenvolvimento inicial no Windows utilizando Lazarus.

Posteriormente, o projeto será compilado e executado em ambiente Linux.
